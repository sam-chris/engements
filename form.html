Form Questions

1. The action attribute tells the form where to send the information when the user submits it.

2. The method attribute tells the form how to send the information, either using GET or POST.

3. GET sends the form information in the URL, while POST sends the information in the request body. POST is better for sensitive information, but you still need HTTPS.

4. A pre-set value is information already filled in, while a placeholder is a hint that disappears when you type. A text box uses the value attribute. A textarea puts the text between its opening and closing tags. A select box uses the selected attribute on an option. A checkbox and radio button use checked to be selected automatically. Placeholders work with text boxes and textareas, but not select boxes, checkboxes, or radio buttons.

5. HTML5 added these input types: email, url, tel, search, number, range, color, date, time, datetime-local, month, and week. It also added new form controls like datalist, output, and progress. In my form, I used text, password, and submit, which were already available before HTML5.
