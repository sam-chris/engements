Questions

1. Why don't we use the border attribute? We don't use the border attribute because CSS is a better way to style a table. CSS gives us more control over the borders, colors, spacing, and overall appearance of the table.

2. What is the easiest way to color every other row a different color? The easiest way is to use the CSS nth-child() structural pseudo-class. It automatically selects alternating rows without adding a class to every row.

3. What does the value in the parentheses of your structural pseudo-class mean? The value tells CSS which elements to select. The value even selects the second, fourth, and sixth elements. Another value is odd, which selects the first, third, and fifth elements.
