1. Why is the viewport meta tag important?

The viewport meta tag is important because it helps the website fit different screen sizes like phones, tablets, and computers. It makes the website easier to read and use on mobile devices.

2. How can you adjust the CSS for printing?

I can adjust the CSS for printing by using @media print in my CSS file. This lets me change colors, font sizes, and hide things like navigation bars when someone prints the page.

3. When would you want to adjust the CSS for printing?

I would want to adjust the CSS for printing when someone needs to print my website. It helps make the page look cleaner, saves ink, and makes the information easier to read on paper.
