Questions

1. What is AJAX?

AJAX lets a website send and receive data from a server without reloading the page.

2. Why do you put your JS code in a separate file?

It keeps the HTML organized and makes the JavaScript easier to read, edit, and debug.

3. How do you use DevTools to debug your JavaScript? How do you find the line number of an error?

I open DevTools by pressing F12 and check the Console for errors. The error message shows the file and line number where the problem happened. I can click it to find the error.

4. Do your form and fields have the same ids that your JavaScript uses? Does the Console show any errors? List your ids, and fix any errors before you submit.

Yes, the ids match. My ids are myForm, fullname, email, pass, state, comments, and message. I fixed the mismatched ids and removed the missing bdate reference. I will check the Console for errors when testing the form.
